# LowArc

A game engine built around small, independently-loadable modules.

Most engines are all or nothing. Adopting one means taking its language, its editor, its project
format and its way of thinking together, and wanting one piece means taking all of them. LowArc is
assembled instead of adopted. You choose the modules you want — a drawing surface, audio, input,
whatever else — and those modules are the framework your code is written against.

The engine itself has no language of its own and no project format. Your code is written in whatever
language you chose, and LowArc has no opinion about it.

## Status

Early, and honest about it: nothing is released yet and there is nothing to download. Releases will
live at [lowarc.com](https://lowarc.com) once there is something worth downloading.
